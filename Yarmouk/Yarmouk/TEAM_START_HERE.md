# UIMS Team Starter

This branch adds skeleton pages, shared layouts, per-page CSS and JS, and beginner-friendly models and service examples.

Login and mandatory student password setup are implemented. Read [AUTH_SETUP.md](AUTH_SETUP.md) for Firebase configuration and [TEAM_DEVELOPER_GUIDE.md](TEAM_DEVELOPER_GUIDE.md) for the ready session, guards, models, services, and Firebase helpers. Other feature pages remain skeletons.

Do not merge before Visual Studio build and security review. All Firebase data writes require authenticated authorization and RTDB rules.

Pages are placeholders, not implemented features. Use a new branch from this branch to test, then PR into develop after team review.
